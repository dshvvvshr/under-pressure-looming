# Under Pressure Looming + Prime Directive Zero
## Unified Repository Guide

**Goal:** Keep every capability from Under Pressure Looming (UPL) while ensuring Prime Directive Zero remains the immutable core principle.

### What Continues from Both
- **UPL Architecture:** Three parallel layers (Core, Nuance, Analytical), agent coordinator, and self-evolving learning loop.
- **Prime Directive Zero:** Immutable substrate that asks, “Does this infringe upon the inalienable right to pursue happiness?” Final decisions still flow from this core.
- **Learning & Storage:** Decisions and learned rules persist for continuous improvement without touching the Core.

### Starting a Fresh Repo
1. Clone or initialize the repo in any path (`/path/to/under-pressure-looming`).
2. Install dependencies: `pip3 install openai` (add agent keys if integrating Grok/ChatGPT).
3. Run the system or tests from anywhere—imports are now repo-relative.
4. Learning artifacts are stored under `learning/data/` (ignored by git) so evolution works in every location.

### How the Pieces Fit
```
USER REQUEST
   ↓
[CORE (Prime Directive Zero)]  ← Immutable “stop the infringement?” check
[NUANCE]                      ← Guidance and alternatives
[ANALYTICAL]                  ← Outcome prediction and risk flags
   ↓ (combined)
CORE FINAL DECISION → Agents (optional) → User
```

### Key Behaviors to Preserve
- Core immutability and Prime Directive Zero framing.
- Parallel layer execution with combined decision at the Core.
- Self-evolving rules that never modify the Core.
- Agent coordination that respects Core outcomes.

This keeps every promise of Prime Directive Zero while retaining the full UPL architecture in a location-agnostic repository.
